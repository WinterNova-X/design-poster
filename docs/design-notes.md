# 设计系统说明 Design Notes

记录 design-poster 各条硬规则背后的理由。改动规则前先读这里——如果理由已不成立，连同学段一起改；如果仍然成立，保持规则。

## 为什么默认融入式全板，50/50 作为可选

最初版本默认"上半实拍 + 下半系统"的 50/50 分割。实测后发现：分割区让照片和图形系统各占一半，边界生硬，画面容易"两张皮"——照片是照片，包装是包装。融入式全板把主体直接提炼成图形贯穿所有载体，画面融洽、系列感更强，用户确认更喜欢这种效果，因此改为默认。

50/50 没有删除：它适合"想保留一张珍贵实拍"的场景（纪念照、地标打卡），作为可选模式保留，需要用户点名才启用。

## 为什么下半区是提炼而不是复制

直接把照片印在包装上，得到的是"纪念品"；把轮廓、姿态、叙事提炼成图形资产再应用，得到的才是"品牌"。这也保证了系统可延展：图形可以用在照片拍不到的角度和载体上（盒侧、封口、纹样），而照片只能贴。

## 为什么色板锁死

系列感来自约束。dusty rose 跳点是唯一的"人声"，其余全是"空气"；一旦允许自定义色相，两次生成之间就会失去家族关系，画面滑向商品渲染。允许变化的只有三处：主包装主色在蓝域内轮换、背景在米白域内轮换、跳点色的位置。变面积不变色相。

## 为什么暖调照片不调蓝

色板是冷调的，但原片若是暖调（黄昏、灯泡、炉火），强行调蓝会毁掉上半区的真实感。规则是让上下两区形成"证据与系统"的对照：证据保留它的温度，系统保持它的克制。对照本身就是设计。

## 为什么文字要定稿在先

图像模型生成文字必然出错，且错得越多越像杂货。定稿每一条文案（内容 + 载体 + 排法）并写进提示词，配合"no other invented text"收尾，把文字从随机项变成设计项。主标题全画面最多完整出现 2 次——重复贴标是最快的廉价感来源；其余物料靠编号、品类小字和纹样识别，这正是一个真实品牌系统的工作方式。

## 为什么载体清单每次重选

固定品类组合（永远是纸袋+盒子+贴纸）会让第二张海报开始就是模板。载体必须能被主题解释：猫的照片出现养护卡是巧思，出现杯套就是凑数。每次重选的代价是需要更多判断，收益是每张海报都从照片里"长"出来。

## 为什么是提案板而不是 mockup 堆

mockup 倾倒（十几个透视各异的商品塞满画面）是素材站审美。提案板使用网格、边缘对齐、尺度反差和大面积留白，让观者能读出"设计逻辑"：谁是核心图形、谁是主包装、文字如何在不同载体上变形。丰富但不拥挤，是这块板子的成品标准。

## 为什么光只用来揭示材质

纸张工艺（厚度、折痕、压纹、模切）是这套视觉的"真实感锚点"。一旦出现强反光、金属高光或夸张 3D，纸就变成了塑料，提案就变成了商品渲染。所以光线条款是负向清单：只许做什么，其余禁止。
