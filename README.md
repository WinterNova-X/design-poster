# Design Poster · 照片变品牌包装提案板

把上传的照片重新设计成一页"品牌包装系统提案板"：照片不再是照片，而是把主体的轮廓、姿态、光影记忆点提炼成核心图形，融洽地铺满整张板子。

`design-poster` 是一个 Agent Skill。它不是给照片套滤镜，也不是把照片裁剪拼贴，而是把照片当成"设计种子"：保留主体身份与记忆点，围绕它建立完整、统一、有秩序的品牌视觉系统。

## 核心效果

- 3:4 竖版，高级实体平铺陈列
- 融入式全板：没有照片分割区，主体提炼成图形贯穿全部载体
- 细线钢笔插画 + 单一主题色 + 跳点 ≤10%
- 真实纸张工艺：哑光棉纸、压凸、模切、火漆、棉线、纸胶带
- 文字定稿防乱码：所有文案提前写死，宁可留白不造假字
- 提案板气质：主包装锚点 + 触点物料 + 四栏英文规范区

一句话：**把照片长成一套品牌系统，而不是把照片修成一张图。**

## 适合做什么

- 宠物、人物、产品的纪念提案板
- 小店品牌提案、校园/城市/文旅限定概念
- 给客户演示"一张照片如何长成一个品牌"

## 不适合做什么

- 写真人像精修、电商主图
- 多图拼贴、九宫格
- 信息密度高的图表海报

## 中文操作指南

下面是从安装到出图的一套完整流程。

### 安装方式

把这个仓库放到 Agent 的 skills 目录下即可。

```bash
# ZCode 用户（Windows）
cd C:\Users\你的用户名\.zcode\skills
git clone https://github.com/WinterNova-X/design-poster.git

# Claude Code 用户
cd ~/.claude/skills
git clone https://github.com/WinterNova-X/design-poster.git
```

如果你的 skills 目录在别的位置，直接把整个 `design-poster` 文件夹复制进去就行，目录名保持不变。

### 基础用法

装好后上传一张照片，像平常聊天一样说：

> 用 design-poster，把这张照片做成高级品牌提案板

稍微具体一点：

> 用 design-poster 处理这张照片，保留主体和光影记忆点，做成雾蓝色系的校园限定提案板

批量测试多张照片时：

> 这三张照片每张单独出一版提案板，不要拼在一起

不需要研究提示词——判断、配色、物料、文案全部由 skill 按流程完成。

### 推荐工作流

1. 上传照片。
2. 先识别照片里最重要的 1–3 个记忆点（轮廓、姿态、光影）。
3. Skill 提炼核心图形，扩展成纸袋/礼盒/杯套/票卡/贴纸/信封等载体系统。
4. 生成后检查：版式是否融洽、有没有照片分割区、提炼图形是否一眼认得出主体。
5. 检查文字：主标题拼写、有没有乱码小字。有问题就重生成。
6. 检查密度：丰富饱满但主包装是视觉重心，小物料不喧宾夺主。

## 常见问题

**主体被画成另一个人/另一个产品？**
提示词开头加一句：`以我上传的照片作为结构参考，保留主体轮廓、比例与识别特征，不要改变主体身份`，重新生成。

**文字乱码或出现别的系列名称？**
删掉非必要小字，只保留主标题与编号；结尾保留 `所有文字严格按上述内容呈现，不得生成其他文字`。仍乱就换 GPT-4o / Nano Banana。

**画面太空、只有几件东西？**
小物料区写明：`丰富饱满有层次，大小横竖对比，轻微叠放，12 件左右`，并逐件列举物料类型。

**画面挤成一团、像地摊？**
写明：`主包装保持视觉主导，小物料负责层次，不喧宾夺主`，并删掉 2–3 件次要物料。

**颜色跟参考图串了？**
换掉参考图（参考图会带来它的识别色），并在提示词写明本主题的专属主墨色与跳点。
