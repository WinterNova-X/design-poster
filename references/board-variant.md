# 全板融入式（默认模式）Integrated Board Mode

本文件定义 design-poster 的**默认版式**：照片内容经过提炼后融入整张提案板——主体成为载体上的插画与图形，没有生硬的照片分割区，全画面共用同一套色彩与材质语言。当用户要求"全板、校园限定、城市限定、省限定、奶茶联名风、提案板系列"，或提供了此类参考图，或直接上传照片说"设计海报"时，都执行本模式。

## 版式（唯一模式）

全板包装提案：主体以提炼图形贯穿全部载体——**无照片区、无 50/50 分割**。主题色板：主墨色由主题决定（原片氛围 / 校色 / 地域色 / 品牌色），保留"单一色系 + 中性纸底 + 跳点 ≤10%"纪律。版面为三段式：主包装三件 → 小物料网格 → 信息栏（可叠营销头版层）。

统一遵守：材质条款、文字纪律（标题 ≤2 次全出现、两种字族、文案定稿防乱码）、载体规则、提案板原则、自检清单。

## 版面骨架

1. **上排主包装（视觉重心）**：纸袋 ★ + 奶茶杯（含杯套）+ 翻盖礼盒 ★，三件横排，袋与盒印主插画与标题。
2. **中部小物料网格**：5–6 件，从 carriers.md 选（风琴折页、吊牌、贴纸组、票券/书签/明信片、信封、茶包、和纸胶带、圆贴），大小横竖错开，轻微层叠 ≤3 处。**默认不给小物料写小字 caption**（乱码重灾区），用品类小字或纯图形识别。
3. **底部四栏信息栏**（小衬线体，只保留四栏大标题，栏内条目用图形不用文字）：
   - `VISUAL ELEMENTS` — 4 个编号线稿图形
   - `COLOR PALETTE` — 5 个圆形色点
   - `MATERIAL & PROCESS` — 5 块纸样（cotton paper / emboss / deboss / die cut / vellum）
   - `BRAND NOTE` — 一句斜体品牌注（每系列一句，可读性优先，控制在 15 词内）

## 系列家族标记（3–6 张构成一个系列）

- 角标：`CAMPUS 01` / `CITY 02` / `SERIES 03`……按主题命名，左上角统一位置。
- 印章：一枚汉字红印（校名/地名首字），**全画面只出现在 2 件载体上**。
- 编号彩蛋：票券/卡片上用一个有意义的数字（邮编、年份、门牌），每系列固定一个。
- 主标题：1–2 个英文单词，全大写，衬线体，**只出现在袋与盒上**；副标题小一号。
- 一个系列内：版式、信息栏、印章规则不变；变的是主插画、色板、载体组合。

## 主题色板示例（保持单一色系纪律）

| 主题 | 主墨色 | 跳点 |
|---|---|---|
| 清华 | 去饱和清华紫 | 荷花粉 + 灰绿 |
| 北大 | 去饱和燕园红（绛红） | 湖绿 |
| 西安交大 | 去饱和靛青 | 秋梧桐褐 |
| 四川大学 | 去饱和银杏赭金 | 砖红 + 灰绿 |
| 文理学院 | 青瓷灰绿 | 芙蓉粉 |
| 南阳（月季） | 去饱和灰玫瑰粉 | 湖绿 + 汉石褐 |

选色方法：主墨色 = 主题最有识别度的颜色去饱和到"灰一档"；跳点 = 场景里的次级颜色，永远小于 10%。

## 实测教训（必须写进提示词的防御条款）

以下问题在首轮实测中 6/6 出现，生成前把对应条款加进提示词：

| 症状 | 防御句 |
|---|---|
| 右上角出现真实品牌 logo、雪人吉祥物乱入杯套/贴纸 | 负面清单加：`no brand logos, no snowman mascot, no bubble-tea brand marks, no red logo stamps in corners`；仍出现则换模型（GPT-4o / Nano Banana 关联较弱）或后期裁改 |
| 其他系列的标题串到本张载体上（如杯套印出别的标题） | 每件载体写死"only"句式：`the sleeve is printed ONLY with the sundial illustration, no text`；结尾保留 `All text exactly as specified, no other invented text` |
| 信息栏小字乱码、栏名拼错 | 信息栏只要求四栏英文大标题；栏内条目一律用图形；小物料不写 caption |
| 主标题拼错（WEIMING→WEMING） | 标题所在载体（袋、盒）各写一遍确切拼写并注明 `spelled exactly` |
| 参考图锚带品牌 → 新图串染（贴纸组是重灾区） | 锚图必须为无品牌纯版式板；挂锚时保留完整负面清单并写死贴纸组清单：`the sticker sheet contains ONLY the listed motifs, no characters other than listed`；串染发生后先换锚再重生成，不要只加负面词硬扛 |
| 信息栏中文栏名乱码（"视觉系统"→"小星盘影"） | 栏名一律英文大写（VISUAL ELEMENTS / NATURAL SCENERY / CULTURAL SYMBOLS / LOCAL FLORA / COLOR PALETTE）；栏内只用图形与色点，不写简介文字 |
| 小物料翻倍（六件变两行十二件、标注重复） | 写明 `only ONE row of six small items, no second row, captions must not repeat` |

## 营销头版层（可选叠加）

在版面骨架之上可再加一层"营销海报头版"，用于更接近省限定商业海报的效果：

- **大标题区**：左上中文大字标语（如"快来挑你校园的专属奶茶"，主题词可换色/换字重），占画面上沿约 15–20%。
- **品牌位**：右上角放**用户自己的**品牌名或 logo 描述；没有品牌时用角标或印章代替，不得生成真实品牌。
- **吉祥物（可选）**：仅当用户提供自有吉祥物描述时写入提示词；不得生成任何真实 IP 形象。
- 大标题文字必须提前定稿写进提示词并注明 `spelled exactly`；中文大字建议不超过 12 字，笔画密的字放大时提醒模型保持结构清晰。
- 加了头版层时，三段式版面整体下移，主包装区压缩但不取消。

## 使用句式

用户说"给我出 XX（学校/城市/省份）的限定系列提示词"时：按 SKILL.md 第 2–3 步分析主题识别符号 → 选主题色板 → 按本骨架出中英双提示词 → 加入上表防御条款 → 按 checklist 自检后交付。
