# 载体库 Carriers Library

选载体前先读一遍本文件。规则：5–8 种载体，1–2 个主包装（★）作为视觉重心，至少 1 种大载体 + 2 种小载体，横竖比例与尺寸拉开尺度反差。此表是起点，不是封闭清单——能被主题解释得通的载体都可以自创。

## 按主体类型的推荐组合

### 人物 / 宠物

- 主包装：纸袋（★，核心图形大印袋身）或方盒（★）
- 标配：吊牌（竖排名字）、贴纸组（姿态剪影）、明信片
- 加分：徽章（脸部轮廓简化）、包装纸（纹样）、卡片组（系列编号）

### 植物 / 花艺

- 主包装：花纸封套（★）或种子盒（★）
- 标配：种子袋、养护卡、圆形标签（拉丁学名式排版）
- 加分：书签（叶片剪影）、硫酸纸封、包装纸

### 食物 / 饮品

- 主包装：外带袋（★）或餐盒（★）
- 标配：杯套（环绕文字）、封口贴（封住盒口折翼）、菜单卡
- 加分：火柴盒（做茶包/糖包盒）、票据（小票式说明卡）、贴纸

### 建筑 / 空间

- 主包装：票券册（★）或导览册封套（★）
- 标配：门票（撕票线 + 编号）、明信片（立面剪影）、房间牌
- 加分：帆布袋（线描立面）、和纸胶带（窗格纹样）、折页

### 器物 / 产品

- 主包装：内衬盒（★，开盖露出产品轮廓内衬）或套盒（★）
- 标配：封套（腰封文字）、说明卡、封口贴
- 加分：手提袋、瓶标、卡片组

### 交通 / 旅行

- 主包装：登机牌式票券（★）或地图折页（★）
- 标配：行李牌（透明窗露图形）、贴纸组（路线图钉）、徽章
- 加分：邮折、护照套式封套、明信片

### 自然景观

- 主包装：海报封套（★）或邮折（★）
- 标配：票券（地名 + 编号）、明信片组、挂画卡
- 加分：包装纸（等高线/波纹纹样）、书签、和纸胶带

## 版面权重参考

- 主包装占下区面积的 35–50%，通常放在视觉重心位（下区中左或中右，避免正中呆板）。
- 中型物料（票券、卡片、折页）围绕主包装形成第二层级。
- 小型物料（贴纸、封口贴、徽章）沿网格边缘散点，制造节奏，不超过 3 处层叠。
- 至少一件物料以"使用中"的状态出现：半拆的包装纸、开盖的盒、未撕的票——增加真实提案感，但不做成使用教程。
