# 质检清单 Checklist

交付前逐项过。P0 任何一条不过，重做；P1 两条以上不过，重做；P2 尽量满足。

## P0 · 一票否决

- [ ] 版面融洽，无生硬的照片拼贴区，提炼图形与照片主体一眼同源；主体没有被拉伸、扭曲、换脸、重绘。
- [ ] 没有多张照片拼进同一张海报；多张照片各自独立成板。
- [ ] 所有文字与定稿一致，无乱码、无多余 invented 文本。
- [ ] 全部颜色出自固定色板，没有越系颜色。
- [ ] 是提案板观感，不是电商陈列、不是 mockup 拼贴。

## P1 · 核心质量

- [ ] 核心图形一眼能联想到原主体，且不是照片描摹。
- [ ] 载体 5–8 种，每种都能被主题解释；有 1–2 个明确视觉重心。
- [ ] 大小横竖拉开尺度反差，网格与边缘对齐可辨认。
- [ ] 主标题完整出现 ≤ 2 次，其余物料用编号 / 品类 / 纹样识别。
- [ ] 材质是纸感：有厚度、折痕、压纹或模切细节；无塑料感与强反光。
- [ ] 原照片与图形系统有至少 1 处色彩或图形上的呼应（两种模式都适用）。
- [ ] 跳点色面积 ≤ 10%，且全画面只有一处跳点色家族。

## P2 · 加分项

- [ ] 有 1 件物料呈"使用中"状态（半拆、开盖、未撕），但不变成使用教程。
- [ ] 纹样至少出现在 1 件大面积载体上。
- [ ] 编号 / 品类名作为系统指纹重复出现 ≥ 2 处。
- [ ] 留白充足，画面"丰富但不拥挤"。
- [ ] 连续多张海报时，载体组合、主包装主色、跳点色位置至少换两项。
- [ ] 缩略图尺寸下（约 200px 宽）主包装与标题仍可辨认。

## 多张照片时的附加检查

- [ ] 每张照片有独立主题与主标题（除非用户指定统一品牌）。
- [ ] 输出按顺序编号（海报 1、海报 2……），与照片顺序对应。
- [ ] 各张之间载体组合不复用（参照 carriers.md 的轮换规则）。
